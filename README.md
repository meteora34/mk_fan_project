# 🐉 Mortal Kombat — Ultimate Retro Universe Web Hub

Интерактивная веб-энциклопедия и медиа-хаб, посвященный культовой вселенной **Mortal Kombat**. Проект сочетает в себе атмосферный ретро-дизайн, богатую базу данных по бойцам, лору и звуковым эффектам, а также интерактивную мини-арену.

## ✨ Ключевые возможности

## ⚔️ **Каталог бойцов & Модальные карточки:** 
  - Детальные биографии персонажей (например, Raiden, Scorpion, Sub-Zero).
  - История появлений бойцов во всей серии игр (начиная с MK1 1992 года и до современных частей).
  - Интерактивное описание Fatality и уникальных спецприемов.

  - Симуляция боя между классическими персонажами (Scorpion vs Sub-Zero) с полосками здоровья и кнопками действий.

## 🛠️ Технологии

- **Frontend:** HTML5, CSS3 (Custom Grid/Flexbox layouts, Custom Dark Theme)
- **Logic & Dynamics:** JavaScript (DOM Manipulation, Audio API, Modal Windows logic, Tab switching)
- **Design & UX:** Ретро-шрифты, оригинальная цветовая палитра MK, кастомные иконки.
